# Current consumer contracts

Accepted runtime baseline: Chimera [`389155313ee5b95f4125e64b61077ddf4257e3d6`](https://github.com/hollis-labs/chimera/commit/389155313ee5b95f4125e64b61077ddf4257e3d6), with [public CI 37772928137](https://github.com/hollis-labs/chimera/actions/runs/37772928137): 125 frontend units, 290 application browser cases and 15 upstream frame mechanism groups, plus Go vet/race, typecheck, adapter/example builds and archive integrity. These are aggregate gates, not a claim that every package export, browser or application policy was reviewed. [Historical checkpoints](delivery-status.md) retain their original counts.

The Go packages are public module imports. Frontend adapters are maintained private TypeScript source; registry is released, while host-ui is the reviewed unpublished candidate described in [dependency distribution](scaffold-dependencies.md). Consumer routes, fixture families/clocks, discovery, grants, business effects and viewport composition stay outside Chimera.

## Root and subpath assembly

Use `Assets` rooted at `index.html` (normally `fs.Sub` over a consumer-owned `//go:embed all:dist` tree). Nil assets provide the shared clean-start placeholder; a missing built asset returns 404 and SPA navigation falls back to index. Build the SPA with the same public base as the Go `BasePath`. For `/review`, assets/navigation live under `/review/`, while `/api/...` and `/plugins/...` stay at the origin root. ServeMux canonical slash redirects are normal; a frontend base must never be constructed as `//`. Reserved API/plugin/health mounting collisions and malformed base paths are refused. Applications own root/subpath route and reload acceptance.

`host.New` does not listen or start a subprocess. `Serve` owns the supplied listener through shutdown; `Handler` allows an app to retain its own HTTP orchestration. Callers handle constructor/listener/serve errors and provide cancellation. [Bootstrap commands and exact pins](scaffold-dependencies.md) show the shell-only entry.

## Whole applications

Complete Torque/chat examples can begin with these contracts and the released AppShell, ListPageLayout, DetailPageLayout, OverlaySidebar and chat components. No demonstrated host API expansion is a prerequisite. Choose one viewport AppShell per entry; replacing the lab wrapper is application composition. Native app navigation, default route, current source and permitted selection, page/transcript/detail scroll owners, narrow focus return and optional compact review controls belong to the app.

Fixture clocks are independent. Operations prefix admission does not confer timestamps on communications/admin snapshots. A cutoff change aligns render props and invocation identity, retires transient candidates where required and preserves only documented unrelated scopes. Package/demo region IDs and the authored fixture ledgers are examples, not a universal product contract.

## Limits and disposition

Folio0109 remains backlog until actual upstream thin wiring, temporary materialization/breadcrumbs, generated Go/frontend builds and preset conformance are proved. The local [preset guidance](../presets/chimera-dashboard/README.md) is not adoption. 0110 is done for Parallax and the isolated fake consumer; Tachyon migration remains unimplemented.

Verified frames limit tested surface authority; they do not establish signatures, business grants, universal egress prevention or CPU/memory containment. Self-navigation may issue a request before observed revocation; already executed main-origin code cannot be recalled. Production origins, inherited CSP, runtime inventories and other browsers require consumer verification. See the [full containment limits](frame-delivery.md).

Command0037 tracks an initial/controlled-search active-descendant relation gap; Tooltip0044 tracks explicit semantic responsibility in the installed controlled wrapper. Existing app-owned **public** styling/role/id/describedby seams and bounded native evidence are documented, without private patches or claiming upstream resolution. Optional effectful exports and packages remain unadopted where their public API cannot meet the review policy.
