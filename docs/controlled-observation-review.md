# Controlled observation retry review

Private `/?observationReview=1` (development `/proof/?observationReview=1`) uses exactly four released `@hollis-labs/kit-observe@0.1.1` exports: `ObservationStatus`, `HealthSummary`, `StatCollection`, and `SampleSeriesView` from the charts entry. Existing package versions, lockfile, licenses and emitted adapter configuration stay unchanged. No shared host API is added. The existing observation demo is separate; this private consumer never mounts `DiagnosticPanel`. That export remains partial because its valid presentation unconditionally mounts CopyButton.

The source is explicitly fictional offline evidence: two finite authored receipt snapshots, each with five exact UTC samples in a four-second window. Selecting a receipt chooses an authored snapshot; it never retimestamps a successful response. Initial idle/loading/error states supply no `observedAt` and retry inspection carries `receipt: null`. The window anchor remains separately labelled. There is no fetch, polling, provider access, persistence or successful refresh simulation.

The host owns a manual clock. Freshness equality at 5000ms remains observed; stale begins at 5001ms. Future/invalid clocks, invalid observation receipt text and nonpositive thresholds display unavailable observation time while retaining supplied content. Invalid timestamps are never supplied to the chart. Unsupported resources hide retained content; paused evidence remains paused. Loading/error with a successful receipt keeps evidence and marks refreshing/refresh failed. Health status is returned evidence independent of availability, including healthy/degraded/unhealthy/unknown checks and empty results.

Statistics preserve zero, null and nonfinite values as zero, missing and invalid samples, with count/bytes/seconds/milliseconds/ratio/percent units. The counter series retains exact nonuniform timestamps, a zero, a null gap and a counter decrease. The rendered time scale is independently checked against timestamp positions; two line segments demonstrate the missing sample is not interpolated. The accessible UTC table exposes every exact row. Bounds/truncation are kit metadata, not a remote validator: this consumer authors only five or fewer points within the declared finite window/limit and tests those bounds. Empty series and truncated evidence remain explicit.

Retry is a held local inspection intent through the existing finite presentation session. Immediate callbacks and the producer's commit reread actual admitted Detail currentness, frame epoch/context/source, host instance, durable contribution ID and generation, plus resource, receipt snapshot, appearance, clock and lease. Same-ID g2, owner withdrawal, context/source/frame/resource/receipt/clock/appearance changes and unmount cancel local tickets; the ignored-abort producer may finish but cannot commit. Closing also retires the held ticket. A stale close cannot affect a new inspection. The StrictMode private root creates a fresh effect-owned fixture/session on replay and disposes the captured instance. No claim is made that an external operation was cancelled or rolled back.

Actual keyboard Retry uses the current optional callback; busy inspection removes retry affordances. DetailDialog contains focus and a bounded, internally scrolling body/footer. Normal close routes to a surviving local control; retirement routes to the current host heading. Frame-bound RAF work checks current identity, control epoch, closed state and connected target and is cancelled on cleanup. Stable unrelated owner hooks/styles survive generation/owner/resource/receipt changes; source/context replacement follows the existing deliberate presentation remount policy. Full stylesheet cleanup is checked on unmount.

The browser proof exercises both production and independent development subpath entries with no external or non-GET effect requests, desktop/narrow dark token paint, exact chart geometry/table equivalence, modal viewport bounds and reachable final controls. Existing plugin actions, frame policies, CSS leases, account/chat, shell, voice and other regressions remain required. Folio and Tachyon adoption remain outside this consumer scope.
